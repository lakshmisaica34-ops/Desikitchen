# Mobile filter: Himanshu 40 + extras + post

Priority = use now for pattern research. Later = principle or optional asset. Skip = web-only, 3D/shader, landing-page, or tooling with no screen to map onto. One line each; details in `sites/<slug>.md`, totals in `SCORECARD.md`.

## Priority

- **Mobbin** (12, 5/5): Library of 621,500+ searchable mobile and web app screenshots, plus flows and UI-element indexes from shipped apps. Use for: Discover, Recipe detail, Cook mode, Saved, Collections, tab chrome.
- **Refero Styles** (6, 4/5): 2,000+ AI-readable style records from real product websites, each with color roles, type scale, spacing, components and a DESIGN.md / Tailwind v4 / CSS variables export. Use for: All screens (token roles), Soft.kt docs.
- **The Component Gallery** (7, 4/5): 60 components, 95 design systems, 2,671 examples with usage guidelines, accessibility notes and tone-of-voice notes. Use for: Discover, Import/Review, Recipe detail, Cook mode, Saved, Collections.
- **appshot.gallery** (P8, 4/5): Curated App Store screenshot gallery for ASO and mobile UI, filterable by genre (Food & Drink), tone of voice, style (Flat Design, Minimalist, Photographic), color and font style. Use for: Play Store listing, onboarding hints, Discover hero copy.
- **CTA.gallery** (16, 3/5): Curated CTAs by type: Button, Call-to-Buy, Download, Form, Modal / Pop-up, Newsletter, Pricing / Subscription; filters by industry and mode. Use for: Discover paste strip, Profile / paywall.
- **Pricing Pages** (18, 3/5): Gallery of pricing pages from SaaS, ecommerce and agencies. Use for: Profile / Plus paywall sheet.
- **DESIGN.md (designmd.ai)** (2, 3/5): Community library of DESIGN.md design systems for AI coding tools (Google's open format), plus MCP and CLI. Use for: Process: all screens.
- **MicroKit** (28, 3/5): 54 free copy-paste micro-interactions for React, CSS and Tailwind: animated buttons, hover effects, tabs and inputs. Use for: Tab chrome, PillButton, SoftField, save heart.
- **Fluid Functionalism** (E1, 3/5): Open-source UI system by @micka_design: 8 system pages (Fluid Hover, Motion, Reveal, Surfaces, Sizes, Typography) and 30 components including ChatMessage, AskUserQuestions, InputMessage, InputCopy, Badge, Banner, CarouselDots. Use for: Assistant / Coco, Discover (InputCopy → paste).
- **TypeUI** (E11, 3/5): CLI and MCP that generate SKILL.md or DESIGN.md design-system files (`npx typeui.sh generate --format design`), with a blueprint: Mission, Brand, Style Foundations, Accessibility (WCAG 2.2 AA), Writing Tone, Rules Do/Don't, component rules, QA checklist. Use for: Process: Soft.kt spec, QA.

## Later

- **Navbar Gallery** (14, 2/5): 550+ website navbars by type: Static/Sticky, Dropdown, Mega Menu, Side Bar, Search Bar, Announcement Bar, Full Screen, Breadcrumbs. Use for: Discover top bar (search entry).
- **shadcn/ui** (20, 2/5): Composable, accessible React components that you own as source. Use for: Soft.kt.
- **Motion-Primitives** (23, 2/5): Open-source animated UI kit for React, Next.js and Tailwind. Use for: Import extracting state.
- **Kinetics (Colorion)** (27, 2/5): 162 animated UI examples with CSS snippets, 99 React Spring examples and 153 AI prompts. Use for: Saved list, Import status pill.
- **Kitbitz** (35, 2/5): 2,000+ free hand-drawn illustrations (SVG/PNG, Figma, MCP), CC0. Use for: Saved and Collections empty states (optional).
- **Minimal Gallery** (4, 2/5): Hand-picked minimal websites, templates and tools; categories include App (60) and Food & drink (40). Use for: Mood reference only.
- **Kage** (5, 2/5): 637 designs and 3,379 components from 353 real products, each convertible into a prompt for Claude Code, Codex or Cursor. Use for: Empty states, cards.
- **DesignMD (designmd.me)** (E5, 2/5): Paste a URL, get a DESIGN.md with extracted tokens, typography and component styles, plus HTML preview and Figma import; credit-based. Use for: Process.
- **designmd.supply** (E7, 2/5): Pre-generated, MIT-licensed DESIGN.md files for well-known brands (Apple, Stripe, Airbnb, Linear and more), built from Context.dev styleguide, brand, screenshot and markdown APIs. Use for: Process.
